## 1. Solar Panel Power Output

### Purpose
Visualizes the hourly solar power generation throughout the day (6 AM - 7 PM).

### Formula

```
Power Output (W) = Panel Efficiency × Panel Area × Sunlight Intensity × Power Multiplier
```

### Variables
- **Panel Efficiency** (η): Conversion efficiency (default: 0.2 = 20%)
- **Panel Area** (A): Solar panel surface area in m² (default: 1.5 m²)
- **Sunlight Intensity** (I): W/m² varies by hour and weather
- **Power Multiplier**: Additional scaling factor (default: 1.0)

### Code Implementation

```python
class SolarPanel:
    def __init__(self, efficiency, area, power_output_multiplier):
        self.base_efficiency = efficiency
        self.area = area
        self.power_output_multiplier = power_output_multiplier

    def generate_power(self, sunlight_intensity):
        base_power = self.base_efficiency * self.area * sunlight_intensity
        return base_power * self.power_output_multiplier
```

### Sunlight Intensity Pattern

```python
daily_sunlight_pattern = {
    6: 200, 7: 400, 8: 600, 9: 700, 10: 800,
    11: 900, 12: 1000, 13: 950, 14: 900, 15: 800,
    16: 700, 17: 500, 18: 300, 19: 100
}
# Rainy hours reduce intensity by 70%: I_rainy = I_clear × 0.3
```

### Total Daily Energy

```
Total Energy (Wh) = Σ[hourly_power_output × 1 hour] × weather_multiplier
```

Weather multipliers:
- Clear: 1.0
- Cloudy: 0.95
- Rainy: 0.85
- Windy: 0.9

## 2. Carbon Emissions Comparison

### Purpose
Compares annual CO₂ emissions between solar and grid-powered tuk-tuks.

### Formulas

**Solar TukTuk Emissions:**
```
E_solar (kg CO₂/year) = (Total Solar Energy / 1000) × 0.05 kg/kWh
```

**Grid TukTuk Emissions:**
```
E_grid (kg CO₂/year) = (Average Efficiency × Annual KM / 1000) × 0.4 kg/kWh
```

### Constants
- **Solar Emission Factor**: 0.05 kg CO₂/kWh (solar panel manufacturing)
- **Grid Emission Factor**: 0.4 kg CO₂/kWh (Kenya grid mix)
- **Annual Distance**: 8,000 km (default)

### Code Implementation

```python
SOLAR_EMISSION_FACTOR = 0.05
GRID_EMISSION_FACTOR = 0.4

# Calculate energy consumption
solar_energy_kwh = total_solar_power_generated / 1000
grid_energy_kwh = (df['grid_eff_Wh_per_km'].mean() * annual_km) / 1000

# Calculate emissions
carbon_emissions_solar = solar_energy_kwh * SOLAR_EMISSION_FACTOR
carbon_emissions_grid = grid_energy_kwh * GRID_EMISSION_FACTOR
```

## 3. Total Cost Projection

### Purpose
Projects cumulative costs over 10 years, including initial investment, maintenance, energy, and battery replacements.

### Formulas

**Solar TukTuk Total Cost:**
```
C_solar(year) = Initial_Investment + Σ(Maintenance) + Battery_Replacements
```

**Grid TukTuk Total Cost:**
```
C_grid(year) = Initial_Investment + Σ(Maintenance + Energy_Cost) + Battery_Replacements
```

### Cost Components

| Component | Solar | Grid |
|-----------|-------|------|
| Initial Investment | $4,000 | $3,000 |
| Annual Maintenance | $50 | $60 |
| Panel Maintenance | $30 | — |
| Energy Cost/km | $0 (free) | $0.9/kWh |
| Battery Replacement | $600 @ ~7.4yr | $600 @ ~3.7yr & ~7.4yr |

### Battery Replacement Timing

```python
# Solar battery degrades slower (3% per year)
solar_80_year = -ln(0.8) / 0.03  # ≈ 7.4 years

# Grid battery degrades faster (6% per year)
grid_80_year = -ln(0.8) / 0.06   # ≈ 3.7 years
```

### Code Implementation

```python
for i, year in enumerate(years_arr):
    if i == 0:
        solar_total_cost[i] = initial_investment_solar
        grid_total_cost[i] = initial_investment_electric
    else:
        solar_total_cost[i] = solar_total_cost[i-1]
        grid_total_cost[i] = grid_total_cost[i-1]
        
        # Annual costs
        solar_total_cost[i] += solar_annual_maintenance + solar_panel_maintenance
        grid_total_cost[i] += grid_annual_maintenance + (avg_grid_cost_per_km * annual_km)
        
        # Battery replacements
        if year >= solar_80_year and (i == 0 or years_arr[i-1] < solar_80_year):
            solar_total_cost[i] += battery_replacement_cost
        
        if year >= grid_80_year and (i == 0 or years_arr[i-1] < grid_80_year):
            grid_total_cost[i] += battery_replacement_cost
```

### Break-Even Calculation

```python
break_even_idx = np.where(solar_total_cost <= grid_total_cost)[0]
if len(break_even_idx) > 0:
    break_even_year = years_arr[break_even_idx[0]]
```

## 4. Energy Efficiency by Terrain

### Purpose
Shows energy consumption (Wh/km) for different terrain types, accounting for weight distribution and capacitor assistance.

### Base Energy Formula

```
E_base (Wh/km) = (Power_avg × Time_per_km) / Motor_Efficiency
```

Where:
```
Power_avg = Motor_Rating × 0.30  # 30% for cruising
Time_per_km = 1/30 hour = 0.0333 hours  # at 30 km/h
E_base = max(60, Power_avg × 0.0333 / η)  # minimum 60 Wh/km
```

### Terrain Factors

```python
terrain_factors = {
    "Flat": 1.0,
    "Hill": 1.5,
    "Sandy": 1.8,
    "Rough": 2.0,
    "Downhill": 0.7
}
```

### Total Energy Required

```
E_total = E_base × Distance × Terrain_Factor × Weight_Factor
```

Where:
```
Weight_Factor = Vehicle_Weight / 400 kg
```

### Solar TukTuk Efficiency Compensation

```python
# Solar is heavier but more efficient
weight_penalty = kerb_weight / 400
energy_needed_base = motor.energy_required(distance, terrain_factor, 400)
energy_needed = energy_needed_base * (0.95 ** (weight_penalty - 1))

# Supercapacitor boost (25% of energy from capacitor)
boost_needed = min(energy_needed * 0.25, supercapacitor.charge_level)
remaining_energy = energy_needed - boost_needed
```

### Capacitor = 0 Rule

When `capacitor_capacity == 0`, both solar and grid use identical efficiency values:

```python
if capacitor_capacity == 0:
    for r in results:
        r["solar_eff_Wh_per_km"] = r["grid_eff_Wh_per_km"]
```

### Terrain Multipliers for Plotting

```python
if capacitor_capacity == 0:
    # Use identical multipliers for both
    common_multipliers = {
        "Flat": 1.00, "Hill": 1.08, "Sandy": 1.12,
        "Rough": 1.18, "Downhill": 0.88
    }
    solar_eff_multipliers = common_multipliers
    grid_eff_multipliers = common_multipliers
else:
    # Different multipliers when capacitor present
    solar_eff_multipliers = {
        "Flat": 1.00, "Hill": 1.05, "Sandy": 1.08,
        "Rough": 1.12, "Downhill": 0.90
    }
    grid_eff_multipliers = {
        "Flat": 1.00, "Hill": 1.08, "Sandy": 1.12,
        "Rough": 1.18, "Downhill": 0.88
    }
```

### Code Implementation

```python
def energy_required(self, distance, terrain_factor, kerb_weight=400):
    weight_factor = kerb_weight / 400
    average_power_factor = 0.30
    base_power_watts = self.power_rating * average_power_factor
    base_energy_per_km = (base_power_watts * 0.0333) / self.efficiency
    base_energy_per_km = max(base_energy_per_km, 60)
    energy = base_energy_per_km * distance * terrain_factor * weight_factor
    return energy
```

## 5. Estimated Range by Terrain

### Purpose
Calculates maximum distance achievable on a full charge for each terrain type.

### Formula

```
Range (km) = Available_Energy / Net_Energy_Per_km × Weather_Multiplier
```

### Available Energy

**Solar TukTuk:**
```
E_available = Battery_Capacity × 0.95 + Supercapacitor_Capacity × 0.95
```

**Grid TukTuk:**
```
E_available = Battery_Capacity × 0.95
```

### Net Energy Per Km (with Regenerative Braking)

```python
energy_per_km_base = motor.energy_required(1, terrain_factor, 400)

if vehicle_has_supercapacitor:
    efficiency_bonus = 0.92
else:
    efficiency_bonus = 1.0

net_energy_per_km = energy_per_km_base * efficiency_bonus

# Regenerative braking on downhill
if terrain == "Downhill":
    recovered_per_km = net_energy_per_km * 0.12
    net_energy_per_km -= recovered_per_km
```

### Code Implementation

```python
def calc_range(vehicle, terrain, speed, kerb_weight, trickle_charge, 
               solar_hours=6, weather_type="Clear"):
    terrain_factors = {"Flat": 1.0, "Hill": 1.5, "Sandy": 1.8, 
                       "Rough": 2.0, "Downhill": 0.7}
    terrain_factor = terrain_factors[terrain]
    
    energy_per_km_base = vehicle.motor.energy_required(1, terrain_factor, 400)
    
    if hasattr(vehicle, 'supercapacitor'):
        efficiency_bonus = 0.92
    else:
        efficiency_bonus = 1.0
    
    net_energy_per_km = energy_per_km_base * efficiency_bonus
    
    if terrain == "Downhill":
        recovered_per_km = net_energy_per_km * 0.12
    else:
        recovered_per_km = 0
    
    net_energy_per_km = max(net_energy_per_km - recovered_per_km, 0.01)
    
    if hasattr(vehicle, 'supercapacitor'):
        available_energy = vehicle.battery.capacity * 0.95 + \
                          vehicle.supercapacitor.capacity * 0.95
    else:
        available_energy = vehicle.battery.capacity * 0.95
    
    weather_multiplier = WEATHER_EFFECTS.get(weather_type, 1.0)
    base_range = available_energy / net_energy_per_km
    adjusted_range = base_range * weather_multiplier
    
    return max(0, adjusted_range)
```

## 6. Supercapacitor vs Battery Lifecycle

### Purpose
Compares efficiency degradation over charge/discharge cycles.

### Data Points

```python
cycle_counts = np.array([100, 500, 1000, 2000, 5000, 10000])
supercap_efficiency = np.array([98, 97.5, 97, 96.5, 96, 95.5])  # %
```

Supercapacitors maintain >95% efficiency even after 10,000 cycles, while batteries degrade to ~68%.

### Code Implementation


## 7. Battery Degradation Over Time

### Purpose
Models battery capacity loss over years of operation.

### Formula (Exponential Decay)

```
Capacity(t) = 100 × e^(-λt)
```

Where:
- **λ** = degradation rate per year
- **t** = years of operation

### Degradation Rates

**Solar TukTuk (with supercapacitor assistance):**
```
λ_solar = 0.03  (3% per year)
Capacity_solar(t) = 100 × e^(-0.03t)
```

**Grid TukTuk (battery only):**
```
λ_grid = 0.06  (6% per year)
Capacity_grid(t) = 100 × e^(-0.06t)
```

### End of Life (80% Threshold)

```
t_80% = -ln(0.8) / λ

Solar: t_80% = -ln(0.8) / 0.03 ≈ 7.4 years
Grid:  t_80% = -ln(0.8) / 0.06 ≈ 3.7 years
```

### Code Implementation

```python
years_degradation = np.arange(0, years + 1)

solar_degradation = 100 * np.exp(-0.03 * years_degradation)
grid_degradation = 100 * np.exp(-0.06 * years_degradation)

solar_80_year = -np.log(0.8) / 0.03  # ~7.4 years
grid_80_year = -np.log(0.8) / 0.06   # ~3.7 years

ax.plot(years_degradation, solar_degradation, 'o-', linewidth=3, 
        label='Solar TukTuk (Supercap-Assisted)', color='#1f77b4')
ax.plot(years_degradation, grid_degradation, 's-', linewidth=3, 
        label='Grid TukTuk (Battery Only)', color='#ff7f0e')
ax.axhline(80, color='red', linestyle='--', linewidth=2, 
           label='80% Threshold (End of Life)')
```

## Regenerative Braking

### Solar TukTuk (Enhanced)

```python
def regenerative_braking(self, speed):
    recovered_energy = self.motor.power_rating * speed * 0.07
    self.battery.charge(recovered_energy)
```

### Grid TukTuk (Standard)

```python
def regenerative_braking(self, speed):
    recovered_energy = self.motor.power_rating * speed * 0.05
    self.battery.charge(recovered_energy)
```

Solar recovers 40% more energy (0.07 vs 0.05) due to better power electronics.
